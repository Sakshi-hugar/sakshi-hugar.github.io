FarmGuardian

Weed detection for crop fields

  • YOLOv8
  • Python
  • FastAPI
  • Roboflow
  • Google Colab
  • HTML dashboard

An object-detection system that tells crops from weeds in field images. A YOLOv8 model is served through a FastAPI backend, and a single-page dashboard lets you upload an image and see the detections.

mAP50

Trained on 142 images for 60 epochs on a free Colab T4 GPU. In testing, the model learned one broadleaf crop and flagged grass and wheat as weeds. The next step is more varied data and a single-crop scope.
