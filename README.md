## Featured project

**FarmGuardian** is an object-detection system that tells crops from weeds in field images. A YOLOv8 model is served through a FastAPI backend, with a dashboard for uploading images and viewing detections.

Code: https://github.com/Sakshi-hugar/FarmGuardian
